تطبيق آجر - صدقة جارية على روح أحمد جمال

هذا إصدار أولي (PWA) مجاني.
للتشغيل محليًا: افتح index.html في متصفح حديث. بعض خصائص التثبيت والعمل دون اتصال تتطلب استضافة HTTPS.
للنشر المجاني: ارفع محتويات المجلد إلى مستودع GitHub عام، ثم فعّل Settings > Pages > Deploy from a branch > main > /(root).
بعد نشر الرابط افتحه من Chrome على أندرويد ثم القائمة > Install app أو Add to Home screen.

- السبحة تحفظ العدد محليًا على الجهاز.
- المصحف يفتح Quran.com ويحتاج إنترنت.
- هذا ليس APK تقليديًا؛ إنه تطبيق ويب قابل للتثبيت.
